# JAVA
This repository contains JAVA programs created for learning and practice. It is based on the syllabus of 2025 new BCA courses. It has lab reports questions given by lecturer.

## Topics
- Variable and data types
- If-Else Statements
- Loops
- Methods
- Classes and Objects
- String and StringBuffer
- Inheritance
- Polymorphism
- Exception handling
- Multithreading
- File handling
- Collections and Generics
- Design pattern in Java
    - Singleton pattern
    - Factory pattern
    - Observer pattern
- Lambda Expression
- Stream API
- Optional class
- Method reference
